## ✨ Features

- **Light & Dark Mode**: Real-time theme switching with `next-themes` and CSS variables.
- **3D Perspective Project Cards**: Interactive cards that tilt following cursor coordinates with multi-depth floating elements (`CardContainer`, `CardBody`, `CardItem`).
- **Interactive Photo Stack**: Full-bleed swipeable profile cards built with Framer Motion drag gestures.
- **Skills & Technologies**: Categorized tech stack (Languages, Frontend, Backend & APIs, Data & Storage, Infrastructure & Tools) with smooth scroll-in animations.
- **GitHub Contribution Snake**: Live animated snake game eating commit activity with automatic light/dark mode adaptation.
- **Experience Timeline**: Career history highlighting founding engineering and infrastructure contributions at FlintLab Inc.
- **Fast Single Page Navigation**: Seamless client-side transitions via Next.js App Router.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS & Lucide Icons
- **Animation**: Framer Motion
- **Theming**: Next-Themes (Light / Dark mode)
- **Primitives**: Radix UI
- **Language**: TypeScript

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/kumarram27/kumarram27.github.io.git
cd kumarram27.github.io
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
